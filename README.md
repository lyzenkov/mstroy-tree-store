## Описание

Проект представляет собой реализацию класса `TreeStore` для работы с древовидными данными и Vue-компонента для визуализации этих данных в виде иерархической таблицы с использованием библиотеки AG Grid Enterprise.

### Основные возможности:

- ✅ Хранение и управление древовидными данными (id, parent, label)
- ✅ Поддержка строковых и числовых идентификаторов
- ✅ Эффективные операции с деревом (добавление, удаление, обновление)
- ✅ Визуализация в виде иерархической таблицы
- ✅ Автоматическое определение категорий (Группа/Элемент)
- ✅ Полная поддержка TypeScript
- ✅ Unit-тесты с покрытием

## Функциональность

### Класс TreeStore
- Получение всех элементов
- Получение элемента по ID
- Получение прямых и всех дочерних элементов
- Получение цепочки родительских элементов
- Добавление, удаление и обновление элементов

### Компонент TreeTable
- Отображение данных в виде иерархической таблицы
- Порядковый номер строки (№ п/п)
- Колонка "Категория" (Группа/Элемент)
- Разворачивание/сворачивание групп
- CRUD операции через панель инструментов
- Выделение строки кликом
- Автоматическое раскрытие родителя при добавлении дочернего элемента
